# Contexte global

## Savoir de l'utilisateur

Le coffre Obsidian `~/v4ult` rassemble ce que l'utilisateur a déjà appris et
décidé :

- `Recherche/` : notes de fond (dev, IA, audio…) ;
- `Projets/<projet>.md` : décisions et savoir propres à chaque projet ;
- `Lab/` : journaux des prototypes, dont le code vit dans `~/ciph3r/lab/` ;
- `Skills/` : les skills Claude Code, actives via un lien dans `~/.claude/skills/` ;
- `claude/` : le journal automatique des sessions (écrit par un hook, à ne
  jamais modifier).

Quand une tâche touche un sujet qui y figure peut-être, cherche-le dans le coffre
avant de repartir de zéro. Une note porte un champ `revu` : au-delà de quelques
mois, revérifie ce qui dépend d'une version.

Quand une session aboutit à quelque chose de réutilisable, propose `/capitaliser`
en une ligne à la fin, sans insister.
